# Demo data for TBBPA metabolism in Pumpkin

Demo data for TBBPA metabolism in Pumpkin

## Usage

``` r
data(TBBPA)
```

## Format

A list object with data, mass to charge ratio, retention time and group
information. Three pumpkin seeding root samples' peaks list is extracted
by xcms online.

## References

Hou, X., Yu, M., Liu, A., Wang, X., Li, Y., Liu, J., Schnoor, J.L.,
Jiang, G., 2019. Glycosylation of Tetrabromobisphenol A in Pumpkin.
Environ. Sci. Technol. https://doi.org/10.1021/acs.est.9b02122

# plot the calibration curve with error bar, r squared and equation.

plot the calibration curve with error bar, r squared and equation.

## Usage

``` r
plotcc(x, y, upper, lower = upper, ...)
```

## Arguments

- x:

  concentration

- y:

  response

- upper:

  upper error bar

- lower:

  lower error bar

- ...:

  parameters for \`plot\` function

## Examples

``` r
if (FALSE) { # \dontrun{
plotcc(x,y,upper)
} # }
```

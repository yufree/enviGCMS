# Get the exact mass of the isotopologues from a chemical formula or reaction's isotope patterns with the highest abundances

Get the exact mass of the isotopologues from a chemical formula or
reaction's isotope patterns with the highest abundances

## Usage

``` r
getmass(data)
```

## Arguments

- data:

  a chemical formula or reaction e.g. 'Cl-H', 'C2H4'

## Value

numerical vector

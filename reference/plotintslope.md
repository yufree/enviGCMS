# plot the slope information of integration

plot the slope information of integration

## Usage

``` r
plotintslope(list, name = NULL)
```

## Arguments

- list:

  list from getintegration

- name:

  the title of the plot

## Examples

``` r
if (FALSE) { # \dontrun{
list <- getinteragtion(rawdata)
plotintslope(list)
} # }
```

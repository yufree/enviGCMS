# Plot the intensity distribution of GC-MS

Plot the intensity distribution of GC-MS

## Usage

``` r
plotsms(meanmatrix, rsdmatrix)
```

## Arguments

- meanmatrix:

  mean data matrix of GC-MS(n=5)

- rsdmatrix:

  standard deviation matrix of GC-MS(n=5)

## Examples

``` r
if (FALSE) { # \dontrun{
plotsms(meanmatrix,rsdmatrix)
} # }
```
